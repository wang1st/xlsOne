最后更新：2026-07-23

## 数据基线

- Google Search Console：新属性仍在处理数据，暂无查询词与展示数据。
- GoatCounter：当前仅记录首页、下载、授权等少量访问与点击，样本不足以据此重写页面。
- 搜索结果共性：用户会在“合并”“汇总”“多个工作簿”“同格式”“Power Query / VBA / 合并计算”等表达之间切换；搜索意图同时包含教程型和工具型。

因此，第一批页面采用“一个 URL 对应一个主意图”的方式覆盖真实任务，不用城市、行业或近义词批量制造薄页。

## 防止关键词互相竞争

- 首页保持品牌与产品总述，不扩写成教程。
- `/excel-summary/` 只承接“找工具”的交易型意图。
- 教程页回答“怎么做”，并明确区分“追加行”和“按相同位置合计”。
- 对比页回答“选哪种方法”，不复制教程步骤。
- 案例页围绕组织上报流程、核对与追溯，不堆砌行业名。
- 视频页以真实演示和文字转录为主体，不复制落地页全文。

## 持续优化规则

每月记录 Search Console/Bing 的查询、展示、点击、CTR 和平均排名，并与 GoatCounter 的下载、授权点击一起判断：

1. 有展示、排名 6–20：补充与查询严格匹配的段落和内部链接。
2. 有展示、CTR 低：先调整标题和描述，不立即新建页面。
3. 有访问、无下载：检查首屏承诺、平台支持、隐私说明和 CTA。
4. 同一查询由多个 URL 获得展示：合并内容或收紧页面主意图。
5. 样本不足时只记录基线，不根据少量访问做结论。
