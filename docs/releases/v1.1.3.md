# xlsOne 1.1.3

## 来源追溯交互

- 来源文件较多时，来源明细区域现在支持鼠标滚轮滚动，并显示可拖动、
  可翻页点击的滚动条，能够访问全部来源文件。
- 鼠标移到来源文件名后会显示“定位”按钮；点击文件名会复制该文件的
  完整路径。
- 点击“定位”会在 Windows 文件资源管理器、macOS Finder 或 Linux
  文件管理器中显示并定位对应来源文件。
- 鼠标移到来源值后会显示可点击反馈；点击即可复制该来源的原始显示值。
- 路径和值复制成功后会在窗口底部给出短暂反馈。

## 路径一致性

- 导入工作簿时统一保存为绝对路径，确保来源追溯复制的始终是完整路径，
  同时避免同一文件分别以相对路径和绝对路径重复导入。

## 验证

- 使用 14 个“仙居县”测试工作簿验证来源列表可以滚动到最后一个来源。
- 增加 36 个来源的滚动可达性测试。
- Windows 发布检查会实际点击中文来源路径和值，并验证剪贴板内容。
