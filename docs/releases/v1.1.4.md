# xlsOne 1.1.4

## 文件定位

- Windows 会先检查目标目录是否已在文件资源管理器中打开；如果已经打开，
  就在原窗口或标签页中高亮并聚焦目标文件，只有尚未打开时才创建窗口。
- macOS 在 Finder 后台完成文件定位，再只把目标窗口带到前台，避免其他
  Finder 窗口一起遮挡当前工作区。
- Linux 优先调用桌面环境标准的文件管理器接口，高亮目标文件并复用已打开
  的目录窗口；同时为常见文件管理器提供兼容回退。

## 界面与更新

- 提高 Linux 正文、标题、数值和来源值字体尺寸，使整体视觉大小与正常桌面
  应用保持一致。
- 应用首次显示后会在后台自动检查更新；仅发现更高版本时弹出提醒，并提供
  “立即下载”和“稍后提醒”，无更新或网络异常时不打扰用户。
- 帮助菜单中的手动检查更新也改为后台执行，仍会反馈已是最新版本或网络
  错误。

## 验证

- 增加更新清单解析、平台安装包地址选择和语义版本比较测试。
- 使用严格编译警告和完整纯 C 测试集验证 macOS 构建，并由发布流水线继续
  验证 Windows、macOS、Linux amd64 与 Linux arm64 安装包。
