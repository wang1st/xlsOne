# xlsOne 1.1.1

发布日期：2026-07-28

本版本将跨平台桌面客户端迁移为纯 C11 实现，默认构建与分发流程不再使用或
链接 Qt，避免 Qt 商业许可对客户端分发方式造成限制。

## 纯 C 桌面客户端

- 使用 SDL 2 提供桌面窗口、输入和渲染，使用 Nuklear 提供界面控件。
- 支持拖放或选择多个 `.xlsx`、常见 BIFF8 `.xls` 工作簿。
- 支持多工作表结构校验、智能汇总、来源穿透和工作表切换。
- 支持把选中单元格修正为求和、标签或多值，并恢复自动识别结果。
- 支持 CSV 导出，以及基于原模板保留表头、样式和结构的 `.xlsx` 导出。

## 解析与导出

- OOXML 解析使用项目内 ZIP 读写、zlib 和 Expat。
- BIFF8 支持常见 OLE、SST、数字、公式缓存、布尔值及合并单元格记录。
- 修复带 XML 命名空间的模板无法正确写入导出水印的问题。
- 使用 4 个同模板样本、2 个工作表和 36 个关键汇总值完成导出回读验证。

## 构建与分发

- 根目录 CMake 和 `make` 默认入口已切换为纯 C 版本。
- macOS Universal DMG 静态链接固定版本的 SDL，并内置 Nuklear/SDL
  许可证和第三方组件声明。
- 最终应用链接审计不包含 Qt 库。
- SDL、Nuklear、zlib 和 Expat 均采用允许商业使用的许可证；分发时仍需保留
  相应版权和许可声明。

## 升级说明

1. 退出正在运行的旧版 xlsOne。
2. 打开 `xlsOne-1.1.1-macos-universal.dmg`。
3. 将 `xlsOne.app` 复制到“应用程序”目录并覆盖旧版本。

当前生成物使用临时签名，适合内部验收。本机未配置 Apple Developer 签名
身份；正式互联网分发前需使用 Developer ID Application 证书重新签名，并
完成 Apple 公证。
