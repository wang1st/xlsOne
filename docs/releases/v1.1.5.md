# xlsOne 1.1.5

## Linux 文件定位

- 定位来源文件时，先识别系统默认文件管理器并直接调用其文件选择能力，
  避免通用文件管理器接口被其他桌面进程转发后重复创建目录窗口。
- 已打开目标目录时复用原文件管理器窗口，并继续高亮所定位的文件；仍为
  Nautilus、Nemo、Dolphin、Caja 和 Thunar 保留兼容路径。
