# xlsOne 1.1.2

发布日期：2026-07-30

本补丁版本修复 Windows 中文及长路径工作簿导入，并完善大量工作表时的
标签导航。

## Windows 文件路径

- Windows 应用清单启用 UTF-8 活动代码页和长路径支持。
- 文件读写统一转换为 Unicode 扩展长度绝对路径，兼容中文目录、中文文件名、
  UNC 路径以及超过传统 `MAX_PATH` 限制的路径。
- Windows 自动化测试现在要求工作簿实际导入成功，不再把仅生成空态截图误判
  为中文路径测试通过。
- 新增长中文路径工作簿的底层解析回归测试，并验证选择文件和拖放两种入口。

## 大量工作表导航

- 工作表标签栏增加左右分页按钮和当前范围提示。
- 标签宽度设置上下限，长名称会安全省略，不再把后续标签绘制到窗口之外。
- 支持 `Ctrl+PageUp` 和 `Ctrl+PageDown` 逐张切换工作表。
- 使用 36 个不同宽度标签完成前后分页回归测试，并使用实际 11 工作表文件
  验证第 11 张工作表可显示和选择。

## 升级说明

Windows 用户请退出旧版后安装 1.1.2。此版本使用新的补丁版本号，确保 MSI
和浏览器下载不会继续沿用此前同名 1.1.1 安装包。
