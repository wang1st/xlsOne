# xlsOne 1.0.10

发布日期：2026-07-24

本次版本重点改善穿透检查的可读性与操作效率，并修复 macOS 下修改单元格汇总类型时可能无法保存规则的问题。

## 穿透检查体验升级

- 来源数字采用更醒目的字号、字重和右对齐方式，连续核对多份文件时更容易比较。
- 来源明细默认展开，并汇总显示有效值、空值和缺失值数量。
- “标签”和“求和”现在会明确显示当前选中状态，避免误判单元格正在使用的汇总方式。
- 鼠标移到来源行即可复制数值、复制文件名或在文件管理器中定位原文件；右键可查看更多操作，双击可直接打开来源文件。

## 新增差异检查提示

- 当同一求和单元格至少有 5 个有效数字时，会将每个来源与其余文件来源的典型水平进行保守比较。
- 只有同时满足统计差异和实际差值门槛的来源才会提示“与其他来源差异明显”。
- 这里的“其他来源”指参与该单元格汇总的其他文件，不是与总计值或上一期数据比较。
- 此提示只提供复核线索，不会自动判定数据错误，也不会改变汇总结果。

## 修复 macOS 规则保存失败

- 修复从 DMG 或只读位置启动时，修改单元格汇总类型可能提示“Read-only file system”的问题。
- 修正规则现在保存到系统提供的用户可写数据目录，不再依赖应用启动位置。

## 质量与兼容性

- 新增来源统计、差异判断和穿透侧栏交互测试。
- 完成简体中文、繁体中文、英文和日文界面文案。
- 本次升级不改变 Excel 文件格式和汇总结果格式，可直接覆盖安装。

## 升级方式

退出正在运行的 xlsOne，下载与当前系统对应的 1.0.10 安装包后直接覆盖安装即可。已有规则和工作文件不会因覆盖安装被删除。
