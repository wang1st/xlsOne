## <a id="1"></a>一、市场定位与用户画像

### 1.1 产品定位

表表归一是一款桌面端 Excel 财务报表汇总工具。核心价值：将多份格式相同的 Excel 报表一键合并为汇总表，替代人工逐表核对和手工相加。

### 1.2 目标用户三层结构

| 层级 | 用户群体 | 付费意愿 | 价格敏感度 | 典型场景 |
|------|---------|---------|-----------|---------|
| **核心付费层** | 会计师事务所、审计公司 | 高 | 低 | 批量处理客户财务报表，项目制使用 |
| **稳定付费层** | 企事业单位财务部门 | 中高 | 中 | 月度/季度/年度报表汇总，持续使用 |
| **入门引流层** | 县乡镇基层财政人员 | 低 | 高 | 偶尔使用，单次汇总少量报表 |

### 1.3 各平台用户分布预估

| 平台 | 预估占比 | 用户特征 | 收费策略 |
|------|---------|---------|---------|
| **macOS** | 45% | 审计公司、外企财务、个人开发者 | **核心付费平台** |
| **Windows** | 35% | 企事业单位、政府机关、学校 | **核心付费平台** |
| **Linux/UOS** | 20% | 信创国产化单位、政务部门 | **免费（战略布局）** |

## <a id="4"></a>四、三平台差异化策略

### 4.1 核心逻辑

```
UOS（免费）──→ 占领信创市场 ──→ 形成用户习惯 ──→ 推荐 Mac/Win 付费版
                                         │
Mac/Win（付费）◀──────────────────────────┘
```

### 4.2 各平台详细策略

#### Linux/UOS 平台 — 永久免费

**战略目的：**
1. 占领信创国产化市场，建立品牌认知
2. UOS 用户多为政务单位，是长期关系入口
3. 培育使用习惯后，使用 Mac/Win 的同事会付费
4. 形成"开源+免费"社区口碑，有利于软著申报和项目申报

**免费范围：**
- 全部核心功能（文件导入、Sheet管理、智能聚合、穿透查阅、导出）
- 全功能方案（Schema）管理
- 社区支持（GitHub Issues）

**限制（日后再考虑）：**
- 不提供商业技术支持服务
- 不提供定制化部署
- 打印/导出加水印（暂不实施）

#### macOS 平台 — 旗舰付费

**定位：** 品质体验标杆，利润核心

**差异化优势：**
- Mac 原生 SwiftUI 开发，与系统深度整合
- Mac App Store 分发，苹果生态背书
- Mac 用户付费意愿强（Mac App Store 付费应用均价 ¥68-198）

**分发渠道：**
1. **Mac App Store**（主力）：苹果审核信任背书，自动更新
2. **官网直接购买**：绕过 30% 苹果税，更高利润
3. **Setapp 订阅平台**：月活 100万+ 的 Mac 应用订阅平台

#### Windows 平台 — 大众付费

**定位：** 用户规模最大，薄利多销

**差异化优势：**
- 用户基数最大（中国 Windows 桌面占比 85%+）
- 企事业单位采购主战场
- 可叠加企业版高客单价销售

**分发渠道：**
1. **官网直接销售**（主力）：零抽成
2. **Microsoft Store**：品牌背书，但抽成 15%
3. **国内软件商城**（华军、多特、腾讯软件管家等）

## <a id="6"></a>六、授权管理与技术实现

### 6.1 推荐方案：离线激活 + 在线验证混合

```
用户购买 ──→ 获取激活码（16位字母数字）
                │
    ┌───────────┴───────────┐
    ▼                       ▼
在线激活                  离线激活
（联网发送激活码+设备指纹）  （激活码+设备ID生成
  │                        本地授权文件）
  ▼                         │
服务器验证 ──→ 签发Token    │
  │                         ▼
  ▼                    本地校验 ──→ 激活成功
激活成功
```

### 6.2 反盗版策略分层

| 阶段 | 措施 | 影响 |
|------|------|------|
| **轻度保护**（V1.0） | 激活码+设备指纹绑定，允许3次迁移 | 拦截随手传播 |
| **中度保护**（V1.3） | 在线心跳验证（7天一次），离线宽限期14天 | 拦截长期借用 |
| **完整保护**（V2.0） | 代码混淆 + License Server | 商业级保护 |

> 不建议在 V1.0 就上重保护。创业初期，传播本身也是推广。只要不让"一人购买多人使用"成为常态即可。

### 6.3 技术实现建议

- **激活服务**：用 Cloudflare Workers 或 Deno Deploy 搭建轻量激活 API（免费额度足够支撑万级用户）
- **支付集成**：Lemon Squeezy（国外，抽成5%+50¢）或 面包多/PayPal
- **激活码生成**：基于设备指纹的 HMAC 签名算法
- **数据库**：Cloudflare D1 或 Supabase（免费额度 500MB）

## 附录A：收入计算器公式

```
年收入 = 新用户订阅收入 + 老用户续费收入 + 永久授权收入 + 企业授权收入

其中：
- 新用户订阅收入 = 月新增用户 × 12 × 订阅单价 × (1 - 折扣率)
- 老用户续费收入 = 到期用户 × 续费率 × 续费单价
- 永久授权收入 = 月销量 × 永久单价 × (1 - 折扣率)
- 企业授权收入 = 企业客户数 × 企业版均价
```
