  硬件运行环境：

      - 内存：4GB RAM 及以上

  软件运行环境：
      - 操作系统：macOS 12.0 (Monterey) 或更高版本
      - 依赖框架：SwiftUI / AppKit

  编程语言：Swift、C++

  源程序量：
      Swift 代码：  11,594 行
      C++ 代码：     8,392 行
      ─────────────────────
      合计：        19,986 行

  主要功能和技术特点：
      表表归一 是一款将多张同格式 Excel 报表一键汇总的桌面工具。
      核心功能包括：
      1) 多文件拖拽导入（支持 .xlsx 和 .xls 格式）
      2) 自动工作表识别与切换
      3) 智能单元格聚合算法（标签识别、数值求和、混合类型统计）
      4) 穿透查阅（追溯各原始文件的单元格值）
      5) 汇总结果导出为 Excel 工作簿
      
      技术特点：
      - 采用 Swift 语言开发 macOS 原生应用
      - 基于 CoreXLSX 库解析 .xlsx 文件
      - 自研 BIFF8 解析器支持旧版 .xls 文件
      - 自研 Compound File Reader 解析 OLE2 复合文档格式
      - 采用两阶段聚合算法：聚合性判断 → 执行聚合
      - 支持多种数字格式识别（千分位、欧式格式等）
