一、软件概述

表表归一是一款运行于 macOS 平台的桌面工具，核心功能是将多张
结构相同（同构）的 Excel 报表智能合并为一张汇总表，实现财务
数据的自动化汇总与穿透查阅。

一句话概括：多表归一，一望而知。

主要功能包括：
  - 多文件拖拽导入
  - 自动识别工作表（Sheet）
  - 智能单元格聚合（标签识别、金额求和、混合统计）
  - 穿透查阅（查看各文件原始值）
  - 汇总结果导出为 Excel 文件

适用场景：政府财务部门、企事业单位需要对多个下级单位上报的同格式
报表进行汇总统计的场景。

二、系统运行环境

2.1 硬件环境

  - 处理器：Intel 或 Apple Silicon (M1/M2/M3) 芯片
  - 内存：不少于 4GB RAM
  - 硬盘：不少于 100MB 可用空间
  - 显示器：分辨率不低于 1280×720

2.2 软件环境

  - 操作系统：macOS 12.0 (Monterey) 或更高版本
  - 依赖框架：SwiftUI、AppKit
  - 文件支持：.xlsx (Office Open XML)、.xls (BIFF8)

三、软件安装与启动

3.1 macOS 版本安装

  步骤一：从发布渠道获取 xlsOne.app 应用程序包。

  步骤二：将 xlsOne.app 拖入"应用程序"文件夹。

  步骤三：首次运行时，如系统提示"无法验证开发者"，请前往
          "系统设置 → 隐私与安全性"中点击"仍要打开"。

3.2 启动方式

  方式一：在"应用程序"文件夹中双击 xlsOne 图标启动。

  方式二：在终端中运行以下命令启动：
          open /Applications/xlsOne.app

  方式三：从源码构建运行：
          swift build -c release
          .build/release/xlsOne

3.3 使用 GNU Guix 环境运行（高级用户）

  如果您的系统安装了 GNU Guix，可以直接使用预编译环境运行：
          guix shell --manifest=manifest.scm
          ./run-app.sh

四、主要功能介绍

4.1 文件导入

本软件支持两种文件导入方式：

【拖拽导入】
  将需要汇总的 .xlsx 或 .xls 文件从 Finder 中拖拽到软件主窗口的
  文件列表区域即可完成导入。

【菜单导入】
  点击菜单栏 "文件 → 打开文件..."（快捷键 ⌘O）选择文件进行导入。
  如需追加文件，使用 "文件 → 添加文件..."（快捷键 ⌘⇧O）。

【导入规则】
  - 支持同时导入多个文件（建议不超过 20 个）
  - 每个文件不超过 1000 行数据
  - 文件格式须为 .xlsx（Office Open XML）或 BIFF8 .xls
  - 所有文件应具有相同的工作簿结构（相同的 Sheet 名称和行列布局）

操作图示：

  │  [📂] 拖拽文件到此处                      │

  │  ├─ 乙乡镇决算报表.xlsx                    │
  │  ├─ 丙乡镇决算报表.xlsx                    │
  │  └─ ...                                  │

4.2 工作表管理

导入文件后，软件会自动扫描所有文件中的工作表（Sheet）名称，
并在顶部以标签页形式展示。

【工作表切换】
  点击不同的工作表标签即可切换当前查看和汇总的工作表。
  切换后，软件会自动重新执行该工作表的数据汇总。

【工作表状态标识】
  - 所有文件都包含该工作表：正常显示
  - 部分文件缺少该工作表：以灰色或警告图标标识

操作图示：

  ┌──────────────────────────────────────────┐
  │  工作表: [Sheet1] [Sheet2] [Sheet3] ...  │
  │           ▲ 当前选中                       │
  ├──────────────────────────────────────────┤
  │  （下方显示当前工作表的汇总数据）            │
  └──────────────────────────────────────────┘

4.3 智能单元格聚合

这是本软件的核心功能。对于每个单元格位置（如 B2=科目代码），
软件会跨所有文件进行智能判断和聚合。

【聚合规则】

  ┌────────────┬──────────────┬─────────────────────┐
  │  数据特征   │  判断结果     │  显示方式            │
  ├────────────┼──────────────┼─────────────────────┤
  │ 所有文件值  │  标签型编码   │  显示原始值（如201）  │
  │ 相同       │  不可聚合     │                     │
  ├────────────┼──────────────┼─────────────────────┤
  │ 值不同且    │  金额型数值   │  显示求和结果         │
  │ 都是数字    │  可聚合       │  （如4500.00）       │
  ├────────────┼──────────────┼─────────────────────┤
  │ 值不同且    │  混合类型     │  显示"X条"           │
  │ 包含非数字  │  不可聚合     │  （如"3条"）         │
  ├────────────┼──────────────┼─────────────────────┤
  │ 只有一个    │  直接显示     │  显示该值             │
  │ 文件       │              │                     │
  └────────────┴──────────────┴─────────────────────┘

【数值格式支持】
  - 纯数字格式（如 "1000"）
  - 千分位格式（如 "1,000.50"，支持中英文逗号）
  - 欧式格式（如 "1.234,56"，小数点与千分位互换）
  - 小数值（如 "3950.0"）

4.4 穿透查阅

在汇总表中，用户可以点击任意单元格查看该位置在所有原始文件中的值。

【操作方式】
  鼠标单击（或双击）汇总表中的任意数据单元格。

【查阅面板显示内容】
  - 列出每个文件的文件名称
  - 显示该文件在该单元格位置的原始值
  - 标注当前单元格的聚合方式（标签/金额求和/混合）

操作图示：

4.5 导出功能

将当前的汇总结果导出为标准的 .xlsx 格式工作簿文件。

【操作方式】
  点击工具栏的"导出"按钮，或通过菜单 "文件 → 导出汇总结果"。

【导出内容】
  - 汇总后的数据表（包含聚合结果）
  - 保留原始工作表的行列结构
  - 保留表头信息

【导出文件格式】
  输出为标准 .xlsx 格式（Office Open XML），可用 Microsoft Excel、
  Apple Numbers、LibreOffice Calc 等常用软件打开。

注意：当前版本导出功能为基本实现，后续版本将新增单元格格式保留
（如字体、颜色、边框等样式信息）。

七、使用场景示例

7.1 场景描述

以某县财政局汇总 13 个乡镇决算报表为例。

【原始数据】
  共有 13 个乡镇的决算报表文件，每个文件包含相同的工作表结构和格式。
  例如：
    - 甲乡镇决算报表.xlsx
    - 乙乡镇决算报表.xlsx
    - ...
    - 包含 11 个工作表（Sheet1 ~ Sheet11）

【报表结构】（以 Sheet1 为例）
  ┌──────┬──────┬──────────┬────────┐
  │  A   │  B   │    C     │   D    │
  ├──────┼──────┼──────────┼────────┤
  │ 序号  │ 代码  │  科目名称  │  金额   │
  ├──────┼──────┼──────────┼────────┤
  │  1   │ 201  │ 一般公共  │ 5234.5 │
  │  2   │ 301  │ 政府性   │ 4890.1 │
  │  3   │ 501  │ 社保基金  │ 5343.0 │
  │ ...  │ ...  │   ...    │  ...   │
  └──────┴──────┴──────────┴────────┘

7.2 操作步骤

步骤一：打开 xlsOne 软件。

步骤二：将 13 个乡镇报表文件一次性拖拽到软件窗口中。

步骤三：软件自动扫描所有文件，识别出 11 个工作表，并默认显示
        第一个工作表（Sheet1）的汇总结果。

步骤四：查看汇总结果：
  - B 列（科目代码）：所有文件该列的值相同（如 B2 都是 "201"），
    因此显示原始值 "201"（标签列，不可聚合）。
  - D 列（金额）：各文件的值不同且都是数字，因此显示求和结果。
    例如 D2 显示 "15467.63"（三个乡镇金额之和）。
  - 如有某列部分文件是数字、部分是文字，则显示 "X条"。

步骤五：如需查看某项汇总的明细，点击该单元格，右侧或底部弹出
        "穿透查阅"面板，显示每个文件在该位置的原始值。

步骤六：确认无误后，点击"导出"按钮，将汇总结果保存为 .xlsx 文件。

7.3 验证结果

使用仙居县 13 个乡镇财务报表进行实际验证：
  - 成功解析 13 个 Excel 文件
  - 识别 11 个工作表
  - 金额列正确求和（如合计 15467.63）
  - 标签列正确显示（如科目代码 "201"）
  - 混合类型正确标记（如 "2条"）

八、常见问题

Q1: 拖拽文件后没有反应？
A1: 请确认文件格式为 .xlsx 或 .xls。旧版 .xls (BIFF5/BIFF2) 格式
    暂不支持，请先用 Excel 另存为 .xlsx 格式后再导入。

Q2: 汇总结果显示不完整？
A2: 请确认所有导入的文件具有相同的工作表名称和行列结构。
    如果文件的 Sheet 名称不一致，可能会导致部分数据无法汇总。

Q3: 金额列没有求和而是显示了别的值？
A3: 可能该列中某些单元格的值不是纯数字格式。请检查原始文件中
    是否存在文字、空格或特殊字符混入数值列。

Q4: 能否汇总超过 20 个文件？
A4: 可以，但处理时间会相应增加。建议单次导入文件数不超过 20 个，
    如文件较多，可分批处理后手动合并。

Q5: 导出的 Excel 文件格式是否保留？
A5: 当前版本保留行列结构和数据内容，后续版本将增强格式保留功能
    （字体、颜色、边框、对齐方式等）。

Q6: 软件是否支持 Windows / Linux？
A6: 当前 Swift 版本仅支持 macOS 12.0+。Linux 用户可使用 C++/Qt
    版本（需从源码编译），Windows 版本正在规划中。
