# xlsOne v0.3.0 规则管理简化设计

## 核心理念

每个同构 Excel 结构只对应一个规则文件。规则管理完全透明：用户做修正 → 保存 → 下次自动生效。

## 五条改动

### 1. 同构共享一个规则

`saveCurrentSchema()` 保存前先按指纹匹配已有规则：
- Exact 匹配 → 更新该规则
- 无匹配 → 新建（一个结构一个文件）

### 2. "管理规则" → "查看规则"（简化弹窗）

删掉左侧多规则列表。弹窗只展示**当前活跃规则**的详情：

```
┌─ 查看规则 ──────────────────────────────┐
│                                          │
│  规则名称    文件名_调整记忆               │
│  工作表      5 张工作表                   │
│  修正        12 个                        │
│  - Sheet1 A5 → 标签                     │
│  - Sheet1 B3 → 求和                     │
│  ...                                     │
│                                          │
│  [导出] [导入] [清除规则] [关闭]          │
└──────────────────────────────────────────┘
```

- **导出**：导出当前规则为 JSON 文件（分享给他人）
- **导入**：从 JSON 文件导入规则（接收他人分享）
- **清除规则**：删除当前规则，恢复自动判断
- 无活跃规则时显示"暂无规则"

### 3. "保存规则"去除命名弹窗

- 有活跃规则 → 直接更新
- 无活跃规则 → 自动用 `suggestedAdjustmentMemoryName()`（导出文件名 + "_调整记忆"）

### 4. 移除 matchCount

从结构体、详情显示、Swift UI 全部删除。

### 5. 深色主题空状态优化

EmptyWorkspaceView 在深色主题下提示文字亮度提升。
