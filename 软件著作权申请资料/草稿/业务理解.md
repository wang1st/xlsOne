# 业务理解

- 软件名称：表表归一
- 产品定位：表表归一是一款面向财务、审计和报表统计场景的桌面端 Excel 同构报表汇总软件。用户将多份结构一致的 Excel 工作簿导入后，软件自动校验工作表和行列结构，识别金额、编码、标签等单元格类型，并生成可追溯的汇总结果。
- 面向领域 / 行业：财务报表汇总、审计辅助、企事业单位统计管理
- 核心价值：减少人工逐表复制、核对和手工求和的重复劳动，降低报表汇总出错概率；在自动汇总的同时保留每个单元格的来源明细，便于复核和审计追溯。
- 证据文件：`业务理解证据.md`

## 目标用户

- 企事业单位财务人员
- 审计人员
- 项目经费统计人员
- 需要批量汇总同结构 Excel 表格的业务人员

## 主要业务功能

- Excel文件批量导入
- 工作簿结构校验
- 工作表切换与汇总查看
- 智能单元格聚合
- 来源穿透查阅
- 汇总类型修正
- 规则记忆与方案管理
- 汇总结果导出
- 许可证激活与授权状态展示

## 功能说明

- Excel文件批量导入：支持用户通过拖拽或菜单选择多个 .xlsx/.xls 文件，导入后形成同一批次进行解析和汇总。
- 工作簿结构校验：导入后检查各文件的工作表、行列结构和可合并范围，发现不一致时展示诊断信息，避免结构不同的文件直接混合汇总。
- 工作表切换与汇总查看：识别同一批文件中的工作表，用户可在顶部工作表标签间切换，查看不同表页的汇总结果。
- 智能单元格聚合：根据表头、格式、邻近单元格和多文件纵向数据特征判断单元格应按金额求和、标签保留还是差异项展示，并在网格中显示汇总结果。
- 来源穿透查阅：用户点击任意汇总单元格后，可在侧栏查看该位置来自每个源文件的原始值、空值或缺失状态。
- 汇总类型修正：当自动判断与实际业务口径不一致时，用户可把选中单元格手动标记为标签或求和，并可恢复自动判断。
- 规则记忆与方案管理：用户可保存本批次的修正规则，后续导入相似结构的报表时自动匹配和应用，也可导入、导出、删除规则方案。
- 汇总结果导出：用户确认汇总无误后，可将当前批次的各工作表结果导出为 .xlsx 工作簿，用于归档、分发或继续处理。
- 许可证激活与授权状态展示：桌面端包含试用、在线激活、离线许可证导入和授权状态提示，便于控制软件使用权限。

## 典型操作流程

1. 启动表表归一，进入空白工作台。
2. 拖入或通过菜单导入多份结构一致的 Excel 测试报表。
3. 软件解析文件并校验工作簿结构，展示可合并工作表和诊断结果。
4. 用户切换工作表，查看编码、名称、金额等单元格的汇总结果。
5. 用户点击汇总单元格，在侧栏查看每个源文件的原始值。
6. 如自动识别不符合业务口径，用户对单元格执行标签或求和修正，并可保存为规则记忆。
7. 用户确认结果后，通过导出功能生成汇总 Excel 文件。

## 申请表建议口径

- 开发目的：本软件用于将多份格式相同的 Excel 报表快速合并为一份可复核的汇总工作簿，替代人工逐表核对和手工相加，提高财务、审计和统计汇总工作的效率与准确性，并保留来源明细以满足复核要求。
- 软件的主要功能：Excel 文件批量导入；工作簿结构一致性校验；工作表切换与汇总查看；智能单元格聚合（金额求和、编码/标签保留、差异项展示）；单元格来源穿透查阅；汇总类型人工修正；规则记忆与方案管理；汇总结果导出为 .xlsx；许可证激活与授权状态展示。
- 技术特点：采用 Swift、SwiftUI、AppKit 和 CoreXLSX 实现 macOS 桌面端主程序，核心模块包含 Excel 解析、BIFF8 .xls 解析、同构工作簿校验、智能合并、格式化导出和规则指纹匹配；同时保留 C++/Qt 跨平台实现，覆盖解析、校验、合并、导出、规则持久化和桌面界面。
