表表歸一 快速參考指南

多張同格式 Excel 報表一鍵彙總 — 工業級操作手冊

版本 1.x · 適用於 Linux / Windows / macOS

快速開始

首次使用？按以下 5 步即可完成第一次彙總：

  1. 啟動應用 開啟表表歸一，進入空白工作臺。支援 Linux、Windows、macOS 三大平臺。
  2. 匯入檔案 將多個 .xlsx 或 .xls 檔案拖入視窗，或透過 檔案 → 匯入檔案… 選擇。支援資料夾批次匯入。
  3. 自動校驗 程式自動分析檔案結構，識別可合併的工作表，並在底部狀態列報告校驗摘要。
  4. 檢視結果 點選頂部 Sheet 標籤切換匯總頁，主表格顯示合併後的資料。藍色單元格為可求和數值，點選任意單元格可在右側面板檢視來源明細。
  5. 匯出儲存 確認無誤後，點選工具欄 匯出 XLSX（或 Ctrl+E），選擇儲存路徑即完成。
提示： 匯入前請確保所有 Excel 檔案使用相同的表頭結構和行列布局。結構不一致的工作表會被自動跳過並給出診斷原因。

匯入檔案

支援三種匯入方式，適用於不同工作場景：

方式操作適用場景
拖拽匯入 將檔案或資料夾直接拖入視窗空白區 從檔案管理器快速選取
選單匯入 檔案 → 匯入檔案…（Ctrl+O） 新建工作區、替換當前檔案列表
追加匯入 點選工具欄 追加（Ctrl+Shift+O） 在已有工作區基礎上補充更多檔案

匯入要求

  • 檔案格式：支援 .xlsx（Office 2007+）和 .xls（BIFF8, Office 97–2003）。
  • 結構一致：所有待合併檔案必須包含同名工作表，且該工作表的表頭行列必須完全對齊。
  • 編碼相容：支援中文、英文等 Unicode 內容，無需額外配置。
注意： 如果匯入時出現"解析失敗"，請檢查檔案是否已損壞或被其他程式獨佔開啟。已加密（帶密碼保護）的 Excel 檔案暫不支援。

檢視彙總結果

匯入成功後，視窗上方會顯示所有檢測到的工作表標籤頁：

合併策略

數值列 — 自動合計

金額、數量、百分比等純數值列，程式自動識別並對所有原始檔進行求和彙總。彙總單元格以藍色字型高亮顯示。

文字列 — 公共字首

名稱、編號、專案程式碼等文字資訊，程式取所有原始檔的最長公共字首作為彙總值。若各檔案值不同，則標記為可稽核。

空值處理

若部分原始檔在某單元格無資料，程式預設以非空值彙總。可在右側面板檢視每個原始檔的實際值。

提示： 雙擊任意彙總單元格可展開該單元格在所有原始檔中的原始值，方便審計和校對。

工作表狀態

每個工作表標籤都會顯示其合併狀態：

狀態含義操作
可合併 該工作表在所有原始檔中結構一致，已成功參與彙總 點選標籤檢視彙總資料
已跳過 結構不一致，該工作表未能參與合併 點選標籤檢視診斷原因

常見跳過原因

  1. 表頭行數不一致：不同原始檔的標題行數不同，導致資料區域無法對齊。
  2. 列數不匹配：同一工作表的列數在不同原始檔中存在差異。
  3. 表頭內容不一致：列標題文字不同，程式無法確定列對應關係。
建議： 使用統一的 Excel 模板規範各分支機構/部門的資料填報格式，可大幅減少"已跳過"情況。預定義的模板檔案可用於後續匯入校驗。

穿透查閱

彙總表的每個單元格都支援穿透查閱（Drill-down），幫助追溯資料來源：

  1. 點選單元格：在彙總表格中單擊任意單元格。
  2. 檢視來源面板：右側面板列出該單元格在各原始檔中的原始值，標註檔名和具體數值。
  3. 識別異常：若某個檔案的值與其他檔案差異較大，可快速定位該檔案進行核實。
審計場景： 財務審計中，可逐個單元格穿透檢視各子公司的原始填報資料，驗證彙總結果的正確性。

匯出結果

彙總校驗完畢後，將結果儲存為標準 Excel 檔案：

  1. 確認彙總表資料無誤（必要時可進行單元格修正後匯出）。
  2. 點選工具欄 匯出 XLSX 或使用快捷鍵 Ctrl+E。
  3. 在檔案對話方塊中選擇儲存路徑和檔名。
  4. 匯出的 .xlsx 檔案可用 Excel / WPS / LibreOffice 開啟。

匯出內容說明

  • 每個可合併的工作表在匯出檔案中保留為獨立 Sheet。
  • 數值格式（千分位、小數位、百分比等）儘可能保留原始樣式。
  • 單元格修正結果會反映在最終匯出檔案中。
  • 已跳過的 Sheet 不出現在匯出檔案中。

單元格修正

如果程式的自動判定與預期不符，可以手動修正單元格的聚合方式：

修正型別

型別快捷鍵行為
標籤（Label） 1 強制以文字方式合併（取公共字首），不進行求和
求和（Sum） 2 強制以數值方式合併（累加），即使內容包含文字

操作步驟

  1. 在彙總表中選中一個或多個需要修正的單元格。
  2. 在右側面板點選 標籤 或 求和，或直接按鍵盤 1 / 2。
  3. 底部狀態列顯示已調整數量，可隨時 撤銷（Ctrl+Z）或 清除所有修正。
  4. 點選 恢復自動 可將單個單元格恢復為程式的原始判定。
最佳實踐： 修正完成後，建議將修正規則儲存為修正規則，下次匯入相同結構的檔案時可自動應用。

修正規則

修正規則（Schema）是一組可複用的單元格修正規則。特別適用於週期性重複彙總的場景（如月度/季度財務報表合併）。

核心功能

自動匹配

匯入檔案時，程式自動檢測是否存在匹配的修正規則。若檔案結構與已儲存的規則高度吻合，自動應用已有修正規則。

儲存規則

透過 修正規則 → 儲存當前修正規則（Ctrl+S）將當前工作區的所有修正規則持久化儲存。

管理規則

透過 修正規則 → 檢視當前修正規則 管理已儲存的規則：檢視修正明細、匯入/匯出 JSON 檔案、清除過時規則。

最佳實踐

  • 為每個報表模板建立獨立的修正規則，命名規則如"華東區月度銷售報表"。
  • 使用 .json 格式匯出/匯入修正規則，便於團隊共享和版本管理。
  • 結構發生變化時，及時更新修正規則以避免舊規則錯誤應用。
技術說明： 修正規則基於"結構指紋"（列名 + 行位置 + 資料型別）進行匹配，而非檔名。因此即使檔案來源不同，只要結構一致即可複用規則。

常見問題

Q: 匯入後所有工作表都顯示"已跳過"？

說明原始檔之間結構差異較大。請檢查：

  • 各檔案的 Sheet 名稱是否完全一致。
  • 表頭區域（前幾行）的行數是否相同。
  • 資料列的列數和列標題是否匹配。
  • 是否混入了不同模板生成的檔案。

Q: 數值沒有被正確求和？

可能原因：

  • 單元格內數值被識別為文字格式（如包含空格、貨幣符號）。
  • 該列在模板中被定義為文字標籤列。
  • 解決方法：選中該單元格後按 2 強制標記為"求和"。

Q: 如何批次調整多個單元格？

在彙總表中按住 Ctrl 點選可多選單元格，然後統一按 1 或 2 進行批次修正。批次修正後建議儲存為修正規則。

Q: 修正規則如何共享給同事？

透過 修正規則 → 檢視當前修正規則 → 匯出 將規則儲存為 .json 檔案。同事透過 匯入 按鈕載入該檔案即可。

Q: 支援的最大檔案數量和大小？

理論上無硬性限制，實際取決於可用記憶體。實測單次匯入 100 個檔案（每個約 5MB）可流暢執行。建議單次不超過 200 個檔案以保證互動響應速度。
