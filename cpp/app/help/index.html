表表归一 快速参考指南

多张同格式 Excel 报表一键汇总 — 工业级操作手册

版本 1.x · 适用于 Linux / Windows / macOS

快速开始

首次使用？按以下 5 步即可完成第一次汇总：

  1. 启动应用 打开表表归一，进入空白工作台。支持 Linux、Windows、macOS 三大平台。
  2. 导入文件 将多个 .xlsx 或 .xls 文件拖入窗口，或通过 文件 → 导入文件… 选择。支持文件夹批量导入。
  3. 自动校验 程序自动分析文件结构，识别可合并的工作表，并在底部状态栏报告校验摘要。
  4. 查看结果 点击顶部 Sheet 标签切换汇总页，主表格显示合并后的数据。蓝色单元格为可求和数值，点击任意单元格可在右侧面板查看来源明细。
  5. 导出保存 确认无误后，点击工具栏 导出 XLSX（或 Ctrl+E），选择保存路径即完成。
提示： 导入前请确保所有 Excel 文件使用相同的表头结构和行列布局。结构不一致的工作表会被自动跳过并给出诊断原因。

导入文件

支持三种导入方式，适用于不同工作场景：

方式操作适用场景
拖拽导入 将文件或文件夹直接拖入窗口空白区 从文件管理器快速选取
菜单导入 文件 → 导入文件…（Ctrl+O） 新建工作区、替换当前文件列表
追加导入 点击工具栏 追加（Ctrl+Shift+O） 在已有工作区基础上补充更多文件

导入要求

  • 文件格式：支持 .xlsx（Office 2007+）和 .xls（BIFF8, Office 97–2003）。
  • 结构一致：所有待合并文件必须包含同名工作表，且该工作表的表头行列必须完全对齐。
  • 编码兼容：支持中文、英文等 Unicode 内容，无需额外配置。
注意： 如果导入时出现"解析失败"，请检查文件是否已损坏或被其他程序独占打开。已加密（带密码保护）的 Excel 文件暂不支持。

查看汇总结果

导入成功后，窗口上方会显示所有检测到的工作表标签页：

合并策略

数值列 — 自动合计

金额、数量、百分比等纯数值列，程序自动识别并对所有源文件进行求和汇总。汇总单元格以蓝色字体高亮显示。

文本列 — 公共前缀

名称、编号、项目代码等文本信息，程序取所有源文件的最长公共前缀作为汇总值。若各文件值不同，则标记为可审核。

空值处理

若部分源文件在某单元格无数据，程序默认以非空值汇总。可在右侧面板查看每个源文件的实际值。

提示： 双击任意汇总单元格可展开该单元格在所有源文件中的原始值，方便审计和校对。

工作表状态

每个工作表标签都会显示其合并状态：

状态含义操作
可合并 该工作表在所有源文件中结构一致，已成功参与汇总 点击标签查看汇总数据
已跳过 结构不一致，该工作表未能参与合并 点击标签查看诊断原因

常见跳过原因

  1. 表头行数不一致：不同源文件的标题行数不同，导致数据区域无法对齐。
  2. 列数不匹配：同一工作表的列数在不同源文件中存在差异。
  3. 表头内容不一致：列标题文字不同，程序无法确定列对应关系。
建议： 使用统一的 Excel 模板规范各分支机构/部门的数据填报格式，可大幅减少"已跳过"情况。预定义的模板文件可用于后续导入校验。

穿透查阅

汇总表的每个单元格都支持穿透查阅（Drill-down），帮助追溯数据来源：

  1. 点击单元格：在汇总表格中单击任意单元格。
  2. 查看来源面板：右侧面板列出该单元格在各源文件中的原始值，标注文件名和具体数值。
  3. 识别异常：若某个文件的值与其他文件差异较大，可快速定位该文件进行核实。
审计场景： 财务审计中，可逐个单元格穿透查看各子公司的原始填报数据，验证汇总结果的正确性。

导出结果

汇总校验完毕后，将结果保存为标准 Excel 文件：

  1. 确认汇总表数据无误（必要时可进行单元格修正后导出）。
  2. 点击工具栏 导出 XLSX 或使用快捷键 Ctrl+E。
  3. 在文件对话框中选择保存路径和文件名。
  4. 导出的 .xlsx 文件可用 Excel / WPS / LibreOffice 打开。

导出内容说明

  • 每个可合并的工作表在导出文件中保留为独立 Sheet。
  • 数值格式（千分位、小数位、百分比等）尽可能保留原始样式。
  • 单元格修正结果会反映在最终导出文件中。
  • 已跳过的 Sheet 不出现在导出文件中。

单元格修正

如果程序的自动判定与预期不符，可以手动修正单元格的聚合方式：

修正类型

类型快捷键行为
标签（Label） 1 强制以文本方式合并（取公共前缀），不进行求和
求和（Sum） 2 强制以数值方式合并（累加），即使内容包含文本
单值（Single） 3 保留当前单元格的显示值，并将其标记为手动修正

操作步骤

  1. 在汇总表中选中一个或多个需要修正的单元格。
  2. 在右侧面板点击 标签 或 求和，或直接按键盘 1 / 2。
  3. 底部状态栏显示已调整数量，可随时 撤销（Ctrl+Z）或 清除所有修正。
  4. 点击 恢复自动 可将单个单元格恢复为程序的原始判定。
最佳实践： 修正完成后，建议将修正规则保存为修正规则，下次导入相同结构的文件时可自动应用。

修正规则

修正规则（Schema）是一组可复用的单元格修正规则。特别适用于周期性重复汇总的场景（如月度/季度财务报表合并）。

核心功能

自动匹配

导入文件时，程序自动检测是否存在匹配的修正规则。若文件结构与已保存的规则高度吻合，自动应用已有修正规则。

保存规则

通过 修正规则 → 保存当前修正规则（Ctrl+S）将当前工作区的所有修正规则持久化保存。

管理规则

通过 修正规则 → 查看当前修正规则 管理已保存的规则：查看修正明细、导入/导出 JSON 文件、清除过时规则。

最佳实践

  • 为每个报表模板创建独立的修正规则，命名规则如"华东区月度销售报表"。
  • 使用 .json 格式导出/导入修正规则，便于团队共享和版本管理。
  • 结构发生变化时，及时更新修正规则以避免旧规则错误应用。
技术说明： 修正规则基于"结构指纹"（列名 + 行位置 + 数据类型）进行匹配，而非文件名。因此即使文件来源不同，只要结构一致即可复用规则。

常见问题

Q: 导入后所有工作表都显示"已跳过"？

说明源文件之间结构差异较大。请检查：

  • 各文件的 Sheet 名称是否完全一致。
  • 表头区域（前几行）的行数是否相同。
  • 数据列的列数和列标题是否匹配。
  • 是否混入了不同模板生成的文件。

Q: 数值没有被正确求和？

可能原因：

  • 单元格内数值被识别为文本格式（如包含空格、货币符号）。
  • 该列在模板中被定义为文本标签列。
  • 解决方法：选中该单元格后按 2 强制标记为"求和"。

Q: 如何批量调整多个单元格？

在汇总表中按住 Ctrl 点击可多选单元格，然后统一按 1、2 或 3 进行批量修正。批量修正后建议保存为修正规则。

Q: 修正规则如何共享给同事？

通过 修正规则 → 查看当前修正规则 → 导出 将规则保存为 .json 文件。同事通过 导入 按钮加载该文件即可。

Q: 支持的最大文件数量和大小？

理论上无硬性限制，实际取决于可用内存。实测单次导入 100 个文件（每个约 5MB）可流畅运行。建议单次不超过 200 个文件以保证交互响应速度。
