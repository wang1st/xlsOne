表表帰一 クイックリファレンスガイド

同じフォーマットの複数 Excel 報告書をワンクリックで集計

Version 1.x · Linux / Windows / macOS

クイックスタート

初めてお使いですか？以下の 5 ステップで最初の集計を完了できます：

  1. アプリを起動 表表帰一を開き、空のワークスペースを表示します。
  2. ファイルをインポート 複数の .xlsx または .xls ファイルをウィンドウにドラッグするか、ファイル → ファイルをインポート... を使用します。
  3. 自動検証 アプリがファイル構造を分析し、ステータスバーに検証サマリーを表示します。
  4. 結果を表示 シートタブをクリックして集計ページを切り替えます。青いセルは数値の合計です。任意のセルをクリックするとソースの詳細が表示されます。
  5. エクスポート XLSX をエクスポート （または Ctrl+E）をクリックして保存します。
ヒント： すべての Excel ファイルが同じヘッダー構造とレイアウトを使用していることを確認してください。構造が一致しないシートは、診断理由とともにスキップされます。

ファイルのインポート

3 つのインポート方法をサポートしています：

方法操作用途
ドラッグ＆ドロップファイルまたはフォルダをウィンドウにドラッグファイルマネージャーからのクイック選択
メニューからインポートファイル → ファイルをインポート... （Ctrl+O）新規ワークスペース / 現在のリストを置換
追加追加 （Ctrl+Shift+O）をクリック現在のワークスペースにファイルを追加

要件

  • 形式： .xlsx （Office 2007+）および .xls （BIFF8、Office 97–2003）。
  • 構造の一貫性：すべてのファイルに 同じ名前 のシートがあり、ヘッダーが揃っている必要があります。
  • Unicode 対応；追加のエンコーディング設定は不要です。
注意： インポートに失敗した場合、ファイルが破損している、他のプログラムによってロックされている、またはパスワード保護されていないか確認してください。

集計結果の表示

インポート後、上部にシートタブが表示されます：

マージ戦略

数値列 — 自動合計

金額、数量、パーセンテージなどは自動的に 合計 されます。集計セルは青色でハイライトされます。

テキスト列 — 共通プレフィックス

名前、コード、プロジェクト ID などは、ソースファイル間の 最長共通プレフィックス を使用します。競合はレビュー対象としてマークされます。

空値の処理

一部のソースが空の場合、デフォルトで空でない値が使用されます。ソース値は右侧面板に表示されます。

ヒント： 任意の集計セルをダブルクリックすると、すべてのソースファイルからの元の値が展開され、監査に役立ちます。

シート状態

各シートタブにはマージ状態が表示されます：

状態意味操作
マージ可能ソース間で構造が一致し、シートはマージに参加しました。クリックして集計データを表示。
スキップ済み構造が一致せず、シートは除外されました。クリックして診断理由を表示。

一般的なスキップ理由

  1. ヘッダー行数の不一致
  2. 列数の不一致
  3. ヘッダー内容の不一致
推奨： 支社/部門間で統一された Excel テンプレートを使用すると、スキップを減らせます。

ドリルダウン

各集計セルは ドリルダウン をサポートし、データソースを追跡できます：

  1. セルをクリック
  2. 右の ソースパネル でファイルごとの元の値を確認
  3. 1 つのファイルの値が大きく異なる場合に異常を発見
監査シナリオ： 財務監査中に、セルごとにドリルダウンして結果を検証できます。

結果のエクスポート

検証後、サマリーを標準の Excel ファイルとして保存します：

  1. 集計データが正しいことを確認（必要に応じてセル修正）。
  2. XLSX をエクスポート または Ctrl+E を押します。
  3. 保存パスとファイル名を選択します。
  4. エクスポートされた .xlsx を Excel / WPS / LibreOffice で開きます。

エクスポート内容

  • マージ可能な各シートは独立したシートとして保持されます。
  • 数値形式は可能な限り保持されます。
  • セル修正結果が最終ファイルに反映されます。
  • スキップされたシートは含まれません。

セル修正

自動判定が期待と一致しない場合は、セルの集計方法を手動で修正できます：

修正タイプ

タイプショートカット動作
ラベル1テキストマージ（共通プレフィックス）を強制、合計しない
合計2数値マージ（累積）を強制

手順

  1. 集計表で修正するセルを 1 つ以上選択します。
  2. 右侧面板で ラベル または 合計 をクリックするか、1 / 2 を押します。
  3. ステータスバーに調整数が表示されます。必要に応じて 元に戻す （Ctrl+Z）または すべての修正をクリア を使用します。
  4. 自動に戻す をクリックすると、単一セルを元の判定に戻せます。
ベストプラクティス： 修正後は、同じ構造で再利用できるよう 修正ルール として保存してください。

修正ルール

修正ルール（Schema）は、再利用可能なセル修正セットです。月次/四半期財務報告書などの 繰り返し集計 に最適です。

主要機能

自動マッチング

インポート時に一致するルールを検出し、構造が類似していれば自動適用します。

ルールの保存

修正ルール → 現在の修正ルールを保存 （Ctrl+S）で修正を永続化します。

ルールの管理

修正ルール → 現在の修正ルールを表示 で、詳細の確認、JSON のインポート/エクスポート、古いルールの削除ができます。

ベストプラクティス

  • レポートテンプレートごとに独立したルールを作成します。
  • ルールを .json 形式でエクスポート/インポートし、チームで共有します。
  • 構造が変わったらルールを更新します。
技術的メモ： ルールは「構造フィンガープリント」（列名 + 行位置 + データ型）でマッチングし、ファイル名ではありません。

FAQ

Q: インポート後、すべてのシートが「スキップ済み」と表示されます。

  • 各ファイルのシート名が完全に一致しているか確認してください。
  • ヘッダー行数が同じか確認してください。
  • 列数と列タイトルが一致しているか確認してください。
  • 異なるテンプレートから生成されたファイルが混在していないか確認してください。

Q: 数値が正しく合計されません。

  • セルがテキストとして認識されている可能性があります（空白や通貨記号を含むなど）。
  • テンプレートでその列がラベル列として定義されている可能性があります。
  • 解決方法：セルを選択して 2 を押し、合計を強制します。

Q: 複数のセルを一度に調整するには？

Ctrl を押しながらセルをクリックして複数選択し、1 または 2 を押します。その後、修正ルールとして保存することをお勧めします。

Q: 修正ルールを同僚と共有するには？

修正ルール → 現在の修正ルールを表示 → エクスポート で .json として保存します。同僚は インポート ボタンで読み込みます。

Q: サポートされる最大ファイル数とサイズは？

厳密な上限はありません。使用可能なメモリに依存します。100 ファイル（各約 5 MB）までスムーズに動作することを確認済みです。応答性を保つため、200 ファイル未満を推奨します。
