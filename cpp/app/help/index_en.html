xlsOne Quick Reference Guide

One-click summary of multiple identically-formatted Excel reports

Version 1.x · Linux / Windows / macOS

Quick Start

First time using xlsOne? Follow these 5 steps:

  1. Launch the app Open xlsOne to the empty workspace.
  2. Import files Drag multiple .xlsx or .xls files into the window, or use File → Import Files....
  3. Auto validation The app analyzes file structures and reports a validation summary in the status bar.
  4. View results Click sheet tabs to switch summary pages. Blue cells are numeric sums; click any cell to see source details.
  5. Export Click Export XLSX (or Ctrl+E) to save.
Tip: Make sure all Excel files use the same header structure and layout. Inconsistent sheets are skipped with diagnostic reasons.

Requirements

  • Formats: .xlsx (Office 2007+) and .xls (BIFF8, Office 97–2003).
  • Consistent structure: all files must contain sheets with the same name and aligned headers.
  • Unicode compatible; no extra encoding setup needed.
Note: If import fails, check whether the file is corrupted, locked by another program, or password-protected.

View Summary Results

After import, sheet tabs appear at the top:

Merge Strategy

Numeric columns — Auto sum

Amounts, quantities, percentages, etc. are automatically summed. Summary cells are highlighted in blue.

Text columns — Common prefix

Names, codes, project IDs use the longest common prefix across source files. Conflicts are marked for review.

Empty values

When some sources are empty, non-empty values are used by default. Source values are shown in the right panel.

Tip: Double-click any summary cell to expand the original values from all source files for audit.

Sheet Status

Each sheet tab shows its merge status:

StatusMeaningAction
ReadyStructure is consistent across sources and the sheet participated in the merge.Click to view summary data.
SkippedStructure is inconsistent; the sheet was excluded.Click to view diagnostic reasons.

Common skip reasons

  1. Header row count mismatch across source files.
  2. Column count mismatch for the same sheet.
  3. Header content mismatch; column titles differ.
Recommendation: Use a unified Excel template across branches/departments to reduce skipped sheets.

Drill-down

Each summary cell supports drill-down to trace data sources:

  1. Click a cell in the summary table.
  2. View source panel on the right to see original values per file.
  3. Spot anomalies when one file's value differs significantly from others.
Audit scenario: During financial audits, drill down cell by cell to verify consolidated results.

Export Results

After validation, save the summary as a standard Excel file:

  1. Confirm summary data is correct (apply cell corrections if needed).
  2. Click Export XLSX or press Ctrl+E.
  3. Choose save path and filename.
  4. Open the exported .xlsx in Excel / WPS / LibreOffice.

Export contents

  • Each mergeable sheet is preserved as a separate Sheet.
  • Number formats are retained where possible.
  • Cell corrections are reflected in the final file.
  • Skipped sheets are not included.

Cell Correction

If automatic detection does not match expectations, manually correct a cell's aggregation:

Correction types

TypeShortcutBehavior
Label1Force text merge (common prefix), no summing.
Sum2Force numeric merge (accumulation), even if content contains text.

Steps

  1. Select one or more cells in the summary table.
  2. Click Label or Sum in the right panel, or press 1 / 2.
  3. The status bar shows the adjustment count; use Undo (Ctrl+Z) or Clear all corrections as needed.
  4. Click Restore auto to revert a single cell to the original detection.
Best practice: After corrections, save them as a correction rule for reuse with the same structure.

Correction Rules

Correction rules (Schema) are reusable cell-correction sets, ideal for recurring summaries such as monthly/quarterly financial reports.

Core features

Auto match

The app detects matching rules on import and applies them automatically when structure is similar.

Save rules

Use Correction Rules → Save Current Rules (Ctrl+S) to persist corrections.

Manage rules

Use Correction Rules → View Current Rules to inspect, import/export JSON, or clear outdated rules.

Best practices

  • Create one rule per report template, e.g. "East Region Monthly Sales Report".
  • Export/import rules as .json for team sharing and version control.
  • Update rules when structures change.
Technical note: Rules match by "structure fingerprint" (column names + row positions + data types), not file names.

FAQ

Q: All sheets show "Skipped" after import?

  • Check whether sheet names match exactly across files.
  • Verify header row counts are the same.
  • Verify column counts and titles match.
  • Make sure files are not from different templates.

Q: Numbers are not summed correctly?

  • The cell may be recognized as text (e.g. contains spaces or currency symbols).
  • The column may be defined as a label column in the template.
  • Fix: select the cell and press 2 to force Sum.

Q: How to adjust multiple cells at once?

Hold Ctrl and click cells to multi-select, then press 1 or 2. Save corrections as a rule afterwards.

Q: How to share correction rules with colleagues?

Use Correction Rules → View Current Rules → Export to save as .json. Colleagues load it via Import.

Q: Maximum file count and size?

No hard limit; depends on available memory. Tests show 100 files (~5 MB each) run smoothly. We recommend fewer than 200 files for responsive interaction.
