COMBINE EXCEL FILES

How to combine Excel files with the same template

Bring recurring branch, store or department reports into one workbook while keeping a clear path back to the source values.

By xlsOne · Updated October 29, 2026

“Combine Excel files” can mean two different jobs. You may want to append every row into a longer table, or consolidate matching cells into a summary. xlsOne is built for the second job: workbooks that share a report template, with corresponding worksheets and cell positions. Decide which result you need before choosing a tool.

Choose the right combination method

1. Prepare a clean set of source workbooks

Work from copies. Put only the reports for the intended reporting period into your source folder. Keep an earlier consolidated output elsewhere so you do not accidentally include it as another input. Check for duplicate files, revised submissions and missing branches.

xlsOne imports .xlsx and common BIFF8 .xls workbooks. A filename extension alone does not prove the workbook is compatible: older or unusual Excel variants may need conversion to .xlsx first. Open each report and confirm it contains the period you expect.

2. Check the template before adding values

Compare worksheet names, row labels, column labels and cell positions. A revenue figure at C8 in one workbook must refer to the same measure at C8 in the others. A newly inserted row can shift the report even when the sheet looks similar. Align those differences before trusting a total.

Also check units and currency. Do not add a report stated in thousands to a report stated in whole currency units. If one source contains percentages, balances or cumulative totals, decide whether summing them is meaningful. Matching positions do not guarantee matching accounting meaning.

3. Import and review in xlsOne

Download xlsOne for your operating system and import the matching workbooks together. Review how worksheets correspond, inspect differences and check the consolidation before export. Spreadsheet contents are processed on your computer; activation, update checks and billing use online services.

Use source tracing on a few important results, including revenue, expenses and any unusual movement. Compare the contributing values with the source reports. Do not rely only on a plausible grand total: missing or duplicated inputs can cancel each other out in the final figure.

4. Export a separate summary workbook

Export the consolidated result as a new .xlsx file. Keep the input workbooks and the exported summary separately so the process is easy to review next month. Your source files remain unchanged. Before distributing the report, check the final period, units and important totals in the exported workbook.

A practical month-end checklist

  • One intended version of each branch or department report.
  • The same reporting period, currency and units across the inputs.
  • Aligned worksheets, labels and numeric cell positions.
  • Source tracing checked for important totals and exceptions.
  • A new output file kept separately from the source folder.

When this workflow is not a fit

If each workbook contains transaction rows that need to be stacked, a consolidation of matching cell positions is the wrong result. For append-style data preparation, consult Microsoft’s guide to combining files in Power Query.
