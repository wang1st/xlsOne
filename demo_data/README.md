# 表表归一宣发演示数据 V2

场景：集团总部每月向 120 家分公司下发统一经营月报模板，各单位填报后返回，由总部集中汇总。

生成：

```powershell
python promo_video\demo_data_v2\generate_demo_workbooks.py
```

输出：

- `workbooks/`：120 份结构完全一致的 `.xlsx` 月报，文件名为“城市名+分公司”
- `recording_workbooks/`：与 `workbooks/` 内容相同的录屏专用副本
- `manifest.json`：单位清单、预期集团汇总值及 5 个预设异常

工作表顺序：

1. 经营数据汇总
2. 费用明细
3. 人员情况
4. 项目交付
5. 回款情况
6. 异常与说明
7. 填报信息

设计原则：第一页只放可直观加总的经营指标；不使用合并单元格和跨表公式；文本差异及单位身份信息放在后两张工作表。
